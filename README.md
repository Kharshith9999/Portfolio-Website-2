# Koneti Harshith - React Portfolio

A responsive, single-page React/Vite portfolio based on the supplied CV.

## Run locally

With Node.js available:

```powershell
npm run dev
```

Then open the local URL shown in the terminal.

For a production check:

```powershell
npm run build
```

## Adding project notebooks

Place the future Jupyter notebooks in `notebooks/` using the names listed in `notebooks/README.md`. Until then, each project card gives a polished notice with the exact path to add.
